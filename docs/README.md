# 配布のしかた（CompeMaster Pro V1）

ゴルフ場がコンペの幹事に配る、コンペ運営アプリ 1本です。

| ファイル | 用途 |
|---|---|
| `pc.html` | **アプリ本体**。参加者・組み合わせ・スコア集計・予想ゲーム・表彰式の演出 |
| `index.html` | `pc.html` へ送るだけの転送ページ。トップのURLを開いた人が迷わないためのもの |
| `404.html` | 存在しないURLを開かれたときに、本体へ送り返すページ |
| `sw.js` / `pc.webmanifest` / `icon-*.png` / `apple-touch-icon.png` | ホーム画面への追加とオフライン動作に使う部品 |

全部で10ファイルです。**まるごと1組で扱ってください。**

> **開発中（M1 まで）です。** お金は経費の割り勘だけになりました（予想の代金・賞金・罰金の精算はありません）。
> 予想ゲームのポイント（pt）は、まだ入っていません（M2〜M3）。いまは的中した口数と、選抜者に負けた数だけを出します。

---

## 方法A　置くだけで全員が使えるようにする（おすすめ）

このフォルダの中身を**まるごと**、HTTPSで見られる場所に置きます。URLを配れば全員が使えます。

**V1 は独自ドメインの直下（`/`）に置きます**（`404.html` がその前提で書いてあります）。
配信には、ファイルを置くだけの静的ホスティング（Cloudflare Pages・Netlify など）を使います。

**社内版（v68）と同じドメインに置かないでください。** 同じドメインのアプリは端末の保存場所を共有します。
V1 は保存キーを `cmp1.`、キャッシュ名を `cmp1-` で始めて、自分のものにしか触らないようにしてありますが、
v68 の `sw.js` は自分以外のキャッシュをすべて消すため、V1 のオフライン用キャッシュが消されます。

置いたあと：

- パソコン → `pc.html` をブックマーク、またはアドレスバーの「インストール」
- スマホ・タブレット → URLを開いて「**ホーム画面に追加**」でもアイコンができます

**一度開けば、次からは電波がなくても動きます。** ゴルフ場は電波が弱いことがあるので、行く前に一度開いておいてください。

### 公開する前に

、**入力例やサンプルに実在の氏名・生年月日が混ざっていないか**を必ず確かめてください。
検証スイートの `privacy.js` がこれを機械で検査します。

### SharePointやOneDriveでは使えません

HTMLがそのまま表示されず、ダウンロード扱いになるためです。ホーム画面への追加もオフライン動作も効きません。方法Bで配ってください。

## 方法B　ファイルを直接配る（サーバーを用意しない場合）

`pc.html` をTeamsやメール、USBで配ります。ダブルクリックで開けば、**機能はすべて使えます。**

ただし次の2つは効きません。

- ホーム画面のアイコンからの起動（ブラウザのブックマークで代用）
- サービスワーカーによるオフライン用のキャッシュ（ファイル自体が手元にあるので実害はありません）

**`pc.html` は1ファイルで完結しています。** 外部の読み込みも通信も一切ありません。
USBに入れて持ち歩けるので、当日はこれを控えとして持っていくと安心です。

---

## アプリストアに出すことは考えなくてよいです

- iOS（.ipa）… Apple Developer Program（年間 約12,000円）と審査、または社内配布用の証明書が必要
- Android（.apk）… 提供元不明アプリの許可が要り、端末管理の方針に触れることがあります
- どちらも中身は今のWebアプリを包むだけで、**機能は1つも増えません**

更新のたびに再配布と再インストールが必要になるぶん、むしろ手間が増えます。方法Aで十分です。

## 集計表の取り込みについて

ゴルフ場が出した集計表からスコアを入れる方法です。**正規の手順は1つだけです。**

### 打ち込んで検算する（当日の正規手順）

「スコア入力」の画面で**グロス・HDCP・ネットの3つ**を入れます。
アプリが `グロス − HDCP ＝ ネット` を1行ずつ照合し、○か×を出します。

3つのうち1つでも打ち間違えると崩れるので、**全行が○になればそのデータは正しい**と言えます。
16名なら3〜4分で、しかも正しいと確認できた状態で終わります。

入れたネットは順位の計算には使いません。順位は常に `グロス − HDCP` で出します。

**ゴルフ場にPDFなど別の形式を頼む必要はありません**（2026-09-18に決定。文字認識を検討していた頃の宿題の名残で、打ち込んで検算すれば足ります）。

### 貼り付け（補助）

手元に文字の集計表（Excel など）があれば、「スコア入力」の貼り付け欄に貼っても入ります。
改行が崩れていても、表が縦向きに読まれていても、アプリが組み直します。
写真から読み取った文字も貼れますが、**取りこぼしと誤読が起きる**ので当てにしません。

**氏名は省略できます。** 数字だけを上から順に貼れば名簿の並びに当てます。
ただし並びを間違えると全員のスコアが入れ替わるので、**貼ったあとも全行が○になることを確かめてください。**

## 更新のしかた

ファイルを差し替えたら、`sw.js` の2行目にある

```js
const VER = "cmp1-1.0.0-dev.2";
```

の番号を**必ず1つ上げてください**。ここを変えないと、利用者の端末に古い版が残り続けます。

CSSや画面の見た目を変えたときは、番号を上げても古いまま残ることがあります。
**スマホはホーム画面のアイコンを一度削除して、追加し直してください。**

### ホーム画面のアイコンが404になったら

iOSのアイコンは**追加した瞬間のURLを覚えます**。サイトが404だった時期に追加すると、
以後ずっとそのURLを開きに行って404のままになります。

`404.html` がその場合の受け皿で、どのURLで固定されていても本体へ送り返します。
根本的に直すには、**アイコンを削除し、`pc.html` を開いた画面から追加し直してください。**

コードを変えたら、**検証スイート（29本・2200項目）を必ず全部走らせてください。**
過去に起きた不具合はすべて再現テストとして残してあります。

## 動作環境

- パソコン … Chrome / Edge / Safari の最新版
- iPhone / iPad … iOS 16以降のSafari
- Android … Chrome

インターネット接続、アカウント登録、インストールは不要です。**データは端末の外に出ません。**
