# venues/ — ゴルフ場専用版の設定ファイル

1ゴルフ場＝1つのJSONファイル。ここにファイルを1つ追加し、`tools/build-venue.js` を実行すると、
そのゴルフ場専用のCompeMaster Pro一式（`dist/<slug>/` 以下）が作られる。

## ファイル名

`<slug>.json`（例：`sample-cc.json`）。`slug`は英数字とハイフンのみ。配布URLの一部になる。

## 項目

| キー | 必須 | 内容 |
|---|---|---|
| `slug` | ○ | ファイル名と同じ値。自動保存キー・配布ディレクトリ名に使う |
| `name` | ○ | ゴルフ場名。ヘッダー・タイトルに表示 |
| `courseId` | — | ゴルフ場マスタのコース名（`docs/pc.html`収録の2,254施設から一致する表記）。指定すると起動時に自コースが選択済みになる |
| `courseFrontIdx` / `courseBackIdx` | — | そのゴルフ場の9H区分のうち、前半／後半に使う番号（0始まり）。省略時は0／1 |
| `logoUrl` | — | ロゴ画像のURL。指定するとヘッダーの文字ブランドの代わりに表示される |
| `themeColor` | — | テーマカラー（16進）。省略時は既定の金色（#D9B166） |

## 使い方

```bash
node tools/build-venue.js venues/sample-cc.json
# → dist/sample-cc/ に一式が生成される
```

## 注意

- `courseId`はゴルフ場マスタの表記と完全一致させる。一致しないと自コース選択が効かず、
  起動時は「未選択」のまま（エラーにはならない。手動で選べばよい）
- 複数ゴルフ場を1台の端末で開く場合でも、自動保存はゴルフ場ごとに分離される
  （`golfCompe.autosave.v2.<slug>` というキー名になるため）
